# my-vue-app

This template should help get you started developing with Vue 3 in Vite.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Run build:dist

```sh
cd dist
1. http-server
2. serve -s dist
```

### Run Unit Tests with [Vitest](https://vitest.dev/)

```sh
npm run test:unit
```
